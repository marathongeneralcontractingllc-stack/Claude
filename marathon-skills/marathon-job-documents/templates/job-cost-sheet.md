# Job Cost Sheet (xlsx)

Tabs:
1. **Costs** – Line, Category (Sub / Materials / Labor W-2 / Dumpster / Permit / Other), Vendor, Est $, Actual $, Variance (formula).
2. **Price** – Total cost (formula), Markup % input, Price (formula), Gross margin % = (Price − Cost)/Price (formula, red if under the Marathon Brain floor), Contingency line.
3. **Payments** – Deposit (check ≤ 1/3), draws, change orders, received, balance (formulas).
4. **Subs** – Sub, trade, agreement signed, COI (naming Marathon), W-9, lien waivers per payment (Y/N), flag any N in red.

Use formulas, not hard-coded totals. Style with marathon-theme table rules.
